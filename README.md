# Battery Data Scaling Law


Исследовательский проект про оценку состояния литий-ионных аккумуляторных батарей (SOH) и необходимого количества данных для обучения различных моделей ИИ в различных химических доменах.

Планируется разработать сервис, который по имеющимся данным об аккумуляторах сможет оценивать:

* сколько данных необходимо для обучения модели;
* сколько независимых батарей необходимо;
* сколько сегментов данных нужно с каждой батареи;
* какое качество можно ожидать при разном объёме данных;
* как меняется результат для разных моделей.

В течение проекта будут исследованы разные подходы к обработке данных и построению моделей, а результаты экспериментов будут превращены в работающий ML-сервис.

## Итоговая цель

К концу проекта планируется получить работающий сервис, который позволяет по данным об аккумуляторах оценить **необходимый объём данных для построения модели с заданным качеством**.

Также планируется провести исследование и определить, как на результат влияют:

* количество аккумуляторов;
* количество данных с каждого аккумулятора;
* условия эксплуатации;
* химический состав батарей.
